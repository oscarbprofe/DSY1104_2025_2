Aprendizaje de ReactJS

¿Qué es ReactJS?

ReactJS es una biblioteca de JavaScript creada por Facebook para construir interfaces de usuario. Permite desarrollar aplicaciones modernas de manera declarativa y basada en componentes.

Manera moderna de crear aplicaciones con React

Antes era común crear aplicaciones con create-react-app, pero hoy en día la forma más moderna y eficiente es utilizar Vite.

Ventajas de Vite:

  • Construcciones más rápidas gracias a ESBuild.
  • Hot Module Replacement (HMR) veloz.
  • Soporta TypeScript y JSX de forma nativa.
  • Configuración sencilla y ligera.

Diferencias con otras formas:

  • create-react-app: Lento en compilaciones grandes, menos flexible.
  • Next.js: Permite SSR y SSG, más completo pero más pesado que Vite.

Conceptos fundamentales

SPA (Single Page Application)

Es un tipo de aplicación web que carga una sola página HTML y actualiza dinámicamente el contenido usando JavaScript, sin recargar completamente la página.

CSR (Client-Side Rendering)

El contenido se renderiza en el navegador del cliente usando JavaScript. React tradicional usa CSR.

SSR (Server-Side Rendering)

El contenido se renderiza en el servidor y se envía al cliente como HTML listo para mostrar. Mejora el SEO y la velocidad de carga inicial.

SSG (Static Site Generation)

El contenido se prepara y genera en tiempo de compilación como archivos estáticos listos para servir. Común en frameworks como Next.js.

Ecosistema React

  • React Router: Manejo de rutas en aplicaciones SPA.
  • Redux / Zustand: Manejo de estado global.
  • Next.js: Framework para SSR, SSG y aplicaciones híbridas.
  • TailwindCSS / Material UI: Estilos y componentes visuales.
