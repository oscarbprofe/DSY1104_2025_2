Variables CSS (Custom Properties)

¿Qué son las variables CSS?

Las variables CSS permiten almacenar valores que se pueden reutilizar en todo el documento. Se definen con --nombre-variable y se usan con var(--nombre-variable).

:root { --color-primary: #3498db; --spacing-md: 16px; } .elemento { color: var(--color-primary); padding: var(--spacing-md); }

Ventajas de las variables:

  • Fácil mantenimiento
  • Consistencia en el diseño
  • Cambios dinámicos con JavaScript
  • Responsive design simplificado

Selectores Básicos

1. Selector de Elemento

Selecciona todos los elementos de un tipo específico.

h1 { color: blue; } /* Todos los h1 */ p { margin: 10px; } /* Todos los párrafos */

2. Selector de ID

Selecciona un elemento único con un ID específico.

#introduccion { background: blue; } /* Solo el elemento con id="introduccion" */

3. Selector de Clase

Selecciona todos los elementos con una clase específica.

.seccion { padding: 20px; } /* Todos los elementos con class="seccion" */

Combinadores

1. Combinador Descendiente (espacio)

Este párrafo está dentro de .contenedor-padre (fondo azul claro)

Este párrafo también está dentro, pero anidado más profundo

.contenedor-padre p { background: lightblue; }

2. Combinador Hijo Directo (>)

Este es un hijo directo (borde verde)
Este NO es hijo directo (sin borde)
.contenedor-padre > .hijo-directo { border: 2px solid green; }

3. Hermano Adyacente (+)

Título hermano

Este párrafo es el hermano inmediatamente siguiente (fondo naranja)

Este párrafo NO es el hermano inmediato

.titulo-hermano + p { background: orange; }

4. Hermanos Generales (~)

Otro título hermano

Primer hermano general (verde)

Un párrafo intermedio

Segundo hermano general (verde)
.titulo-hermano ~ .hermano-general { background: green; }

Agrupación de selectores:

h1, h2, h3 { font-family: serif; } p.especial { font-weight: bold; } input[type="text"]:focus { border-color: blue; }
