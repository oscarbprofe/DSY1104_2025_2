💻 Código CSS de Referencia

/* Propiedades del contenedor */
.flex-container {
    display: flex;
    
    /* Dirección */
    flex-direction: row | row-reverse | column | column-reverse;
    
    /* Alineación en eje principal */
    justify-content: flex-start | flex-end | center | space-between | space-around | space-evenly;
    
    /* Alineación en eje cruzado */
    align-items: flex-start | flex-end | center | stretch | baseline;
    
    /* Envolvimiento */
    flex-wrap: nowrap | wrap | wrap-reverse;
    
    /* Shorthand para direction + wrap */
    flex-flow: row wrap;
}

/* Propiedades de los elementos */
.flex-item {
    /* Crecimiento, encogimiento y base */
    flex: 1 1 auto;  /* grow shrink basis */
    
    /* Propiedades individuales */
    flex-grow: 1;
    flex-shrink: 1;
    flex-basis: auto;
    
    /* Alineación individual */
    align-self: auto | flex-start | flex-end | center | stretch | baseline;
    
    /* Orden */
    order: 0;
}

🎓 Tip: Usa las herramientas de desarrollador del navegador (F12) para experimentar con estas propiedades en tiempo real.
